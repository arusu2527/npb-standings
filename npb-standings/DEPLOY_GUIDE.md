# ⚾ NPB順位表システム Web公開マニュアル

本システムは、**「PCから今すぐワンクリックで世界中に公開する方法」**と、**「PCを消しても24時間常時アクセスできる無料クラウド公開」**の両方に対応しています。
どちらの方法でも、**「本日のアクセス数」**と**「総アクセス数」**が画面上（ヘッダー右上およびフッター）に自動集計・表示されます。

---

## 方法1: PCからワンクリックで今すぐ公開（おすすめ・設定不要）

アカウント登録や面倒な設定なしで、今すぐ誰でもアクセスできるURLを発行できます。

### 手順
1. フォルダ内の **`start_public_server.bat`** をダブルクリックします。
2. 自動的にサーバーが立ち上がり、世界中からアクセス可能な **専用URL（HTTPS）** が発行されます。
   - 例: `https://xxxx-xxxx.trycloudflare.com`
3. 自動的にブラウザが立ち上がります。
4. 黒い画面（コマンドプロンプト）に表示された **「🌐 公開URL」** をコピーして、スマートフォンや知人・友人に共有してください。
   - スマホのカメラで直接読み取れるQRコード用URLも表示されます。
5. 誰かがアクセスすると、ヘッダー右上のカウンター（`本日` / `累計`）に即座に反映されます。

> **注意点:**
> - この黒い画面を開いている間、世界中からアクセスできます。
> - 公開を終了したいときは、黒い画面で `Ctrl + C` を押すか、ウィンドウの「×」ボタンで閉じてください。

---

## 方法2: PCを閉じても24時間いつでも見れる「無料クラウド公開」

自分のパソコンを消していても、24時間365日誰でも見られるようにしたい場合は、無料クラウドサービス（**Render.com**）を利用できます。

### デプロイ手順（所要時間：約5分・すべて無料）

#### ステップ1: GitHubにアップロード
1. [GitHub](https://github.com/) にログインし、新しいリポジトリ（例: `npb-standings`）を作成します。
2. 本フォルダ内のファイル一式をリポジトリにプッシュ（アップロード）します。

#### ステップ2: Render.com で連携
1. [Render.com](https://render.com/) に無料登録（GitHubアカウントでログイン可能）。
2. ダッシュボードで **「New +」➔「Web Service」** を選択します。
3. **「Build and deploy from a Git repository」** を選び、先ほど作成した GitHub リポジトリを選択します。
4. 設定画面で以下を確認・入力します：
   - **Name**: `npb-standings` （お好みの名前）
   - **Environment**: `Python`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python server.py`
   - **Instance Type**: `Free` (無料プラン)
5. 最下部の **「Create Web Service」** をクリックします。
6. 数分待つとビルドが完了し、`https://npb-standings-xxxx.onrender.com` のような専用URLが発行されます！
   - このURLは世界中誰でも24時間アクセス可能で、アクセス数も自動記録されます。

---

## ローカル（自分専用）で使いたい場合

インターネットには公開せず、自分のパソコン内だけで利用したい場合は、
**`start_server.bat`** をダブルクリックしてください。
（`http://localhost:8080` で自分専用のアクセスカウンター付きで起動します）

---

## アクセスカウンターの仕様

- **本日のアクセス数**: 日本標準時（JST）の午前0:00を基準に毎日自動集計されます。
- **総アクセス数**: システム公開開始からの累計アクセス数です。
- **重複リロード防止**: ページを短時間（3分以内）に連続でリロードした場合は重複カウントせず、正確なユニークアクセス数を集計します。
- **データ保存**: 訪問ログおよび日別集計データはローカルの `access_stats.db` (SQLite) に安全に保存されます。
